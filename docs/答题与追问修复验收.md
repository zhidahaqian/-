# 答题跳转与追问输入区修复验收

日期：2026-10-30，时区 Asia/Shanghai。

## 问题与修复

提交非首题的答案后，跳题列表中的作答状态从“未练”变成“已答对”或“待复习”。当前使用的 Streamlit 版本会把变化后的选项文案视为组件身份的一部分，重建选择框，原先因此回到默认的第一题。

现在以独立的 `current_question_id` 保存当前题号，统一处理跳题、前后导航和错题复习，并在组件重建前恢复选择。提交后保留当前题目与反馈；切换页面再返回也保留题号。筛选范围不包含当前题时，才选择该范围的第一题。

模型追问改为有可见标签的多行输入框，加入浅绿色背景、边框、输入示例和明显的“发送追问”按钮，并放在助手回复上方。提交答案前展示禁用状态及说明，提交后启用；空白消息不会发起模型调用。题库解析模式仍使用预设内容。

## 验证结果

- 修复前新增回归用例可复现：在 DS003 提交答案后选中 DS001。
- 修复后本地执行 `python -m pytest -q`，18 项测试通过。出现一条第三方依赖的弃用提示。
- 云服务器以应用运行用户执行部署源码的 Streamlit AppTest，使用独立 SQLite 测试库及模拟模型，不读写正式学习记录，也不发起收费 API 请求。
- 云端验证：DS003 答对后保留原题；DS004 答错后保留原题；切换学习概览再返回保留原题；多行追问显示模拟回复；空白追问无模型请求；DS004、DS005 连续错题复习均可完成且题号不跳回。
- 服务器已备份旧源码并更新 `ds_tutor/practice.py`、`assets/style.css`，重启 `ds-tutor` 服务后状态为 active、enabled，内部健康检查返回 `ok`，正式 SQLite 数据库 `quick_check` 返回 `ok`。

机器可读证据：`evidence/navigation-fix-acceptance.json`，包含验证项目、模拟调用次数和部署文件 SHA-256。
