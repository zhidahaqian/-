# 本机验收记录

日期：2026-10-29（Asia/Shanghai）。

后续进展：2026-10-30 已完成幕僚云部署；公网访问和云端功能验收见《幕僚云部署验收》。下文为 10 月 29 日的历史本机验收状态。

## 环境

Windows，Python 3.13.2，Streamlit 1.50.0。用户显卡为 RTX 3050 Ti Laptop GPU，显存 4096 MiB；本轮 Web 开发及测试未使用 GPU 训练。

## 已执行检查

1. 全部 Python 源文件通过 compileall 语法检查。
2. 初版 `pytest` 12 项测试通过；API 配置刷新功能加入后，13 项测试通过，用时约 13.96 秒。测试客户端依赖有一条弃用提醒，不影响通过结果。
3. `pip check`：无依赖冲突。
4. 本地 Streamlit 健康检查返回 `ok`。
5. 浏览器实际执行：请求预设提示 → 选择错误选项 → 提交 → 标准解析 → 错题本 → 重新练习 → 提交正确答案 → 学习统计。
6. 桌面 1440×1000 和窄屏 390×844 布局检查；窄屏正文宽度 390，无页面级横向溢出。

## 测试覆盖

- 60 道题的字段、ID、答案和筛选；部分计算题用独立算式核对。
- 正误判定、重复提交防护、数据库重启读取、学习者数据隔离。
- 错题从待复习到已复习、作答次数与正确率。
- 不选答案的反馈、缺少 API 配置的反馈、中文访问口令。
- API 请求格式、超时和鉴权错误的处理。此项使用测试桩，没有调用真实商业 API。
- 模型服务的 Bearer 鉴权、模型选择、输入/输出参数限制、基础模型/适配器切换参数。此项用生成测试桩验证接口，没有加载真实权重。
- 数据集题族不交叉、划分可复现、仅助手回答参与损失、超长样本拒绝静默截断。

## 本机服务

交付时服务监听 `127.0.0.1:8501`，仅本机可访问。如果开发会话结束或电脑重启后服务停止，可双击 `启动应用.cmd` 再次启动；此时保留启动窗口即可，按 Ctrl+C 停止。
