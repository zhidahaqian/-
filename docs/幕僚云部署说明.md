# 幕僚云部署与使用说明

记录日期：2026-10-30（Asia/Shanghai）。本次部署继续使用云端模型 API，Web 程序在云服务器上运行，不需要本机保持开机，也不使用 GPU 做推理。

## 1. 访问入口

- 网页地址：<http://140.210.92.250:17078>
- 端口映射：公网 `17078` → 实例内 `8890`。
- 二维码：`screenshots/10-muliao-access-qr.png`，仅包含网页地址，不包含访问口令。
- 网站访问口令由部署时生成，本机保存于 `runtime/muliao-access.txt`；该文件不进入源码包。此口令与 SSH 登录密码不同。

浏览器打开网页后输入网站口令，进入练习工作台。默认使用已配置的云端 API；普通选题、提交和查看标准解析不会请求模型，点击提示、讲解或发送追问时才会调用。

展开侧栏“保存 / 恢复我的学习码”，自行保存学习码。浏览器会话重建后，重新输入网站口令，再用学习码恢复原有答题记录。不要把个人学习码拍进展示截图。

当前入口使用 HTTP，尚未配置域名和 HTTPS。实例需要保持运行；关机期间网页无法访问。公网和重启验收的实际结果见《幕僚云部署验收》。

## 2. 服务器目录与运行方式

| 路径或名称 | 用途 |
| --- | --- |
| `/data/ds-tutor/app/` | 应用源码、题库和说明资料 |
| `/data/ds-tutor/venv/` | 独立 Python 虚拟环境 |
| `/data/ds-tutor/config/server.env` | 服务端模型配置和网站访问口令，仅 root 可读取 |
| `/data/ds-tutor/runtime/study.db` | SQLite 学习记录 |
| `/data/ds-tutor/backups/` | 重装或更新时保留的源码备份 |
| `/etc/systemd/system/ds-tutor.service` | systemd 服务定义 |
| `ds-tutor` | 运行 Web 应用的独立系统用户 |

服务从环境文件读取 API 配置。源码目录没有 `.env`，也没有上传本机的个人答题库。共享模式为每个新会话分配独立学习码。

服务设置了开机启动及异常退出后重启，并限制应用对系统目录的写入。可写学习数据存放于数据盘。关机和重启不等同于删除数据盘；仍需定期备份，释放实例或删除磁盘前应下载数据。

## 3. 日常管理

使用幕僚云提供的 SSH 方式连接后执行：

```bash
systemctl status ds-tutor --no-pager
systemctl restart ds-tutor
journalctl -u ds-tutor -n 80 --no-pager
```

服务器内健康检查：

```bash
curl http://127.0.0.1:8890/_stcore/health
```

正常结果是 `ok`。服务健康不等于模型接口连通；模型需要在网页点击一次提示并检查返回内容。

修改模型地址、模型名、密钥或访问口令时，在服务器终端编辑配置文件并重启：

```bash
nano /data/ds-tutor/config/server.env
chmod 600 /data/ds-tutor/config/server.env
systemctl restart ds-tutor
```

共享部署使用 systemd 环境文件，因此网页中的“重新读取模型配置”不能替代服务重启。不要把密钥写进命令行参数、截图或报告。

停止网页服务使用 `systemctl stop ds-tutor`。这只停止 Web 程序，不会关闭云实例；实例开关机和费用在幕僚云控制台管理。

## 4. 复现部署

前提：Ubuntu、root 安装权限、`/data` 数据盘、8890 端口空闲，以及控制台已经提供对应公网映射。

1. 在本机执行 `python scripts/package_project.py` 生成不含密钥和个人学习记录的源码包。
2. 经 SSH/SFTP 上传源码包为 `/data/ds-tutor/source.zip`，上传 `scripts/deploy/muliao_install.sh`。
3. 创建权限为 700 的 `/data/ds-tutor/config`，在其中准备权限为 600 的 `server.env`。字段包括 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`、`LLM_SEND_ENABLE_THINKING`、`APP_SHARED_MODE=true`、`APP_ACCESS_CODE` 和 `APP_DB_PATH=/data/ds-tutor/runtime/study.db`。
4. 执行安装脚本：

```bash
PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple \
  bash /data/ds-tutor/muliao_install.sh /data/ds-tutor/source.zip
```

脚本只在需要时补装 Python venv 支持，创建应用虚拟环境，安装依赖，注册 systemd 服务并检查健康状态。源码更新前会创建源码备份，不覆盖运行数据库或服务端配置。

执行 `scripts/deploy/inspect_server.py` 可以输出不含密钥和个人记录明细的运行诊断。部署实际安装版本可以通过虚拟环境的 `pip freeze` 留存。首次部署仍需要实际浏览器确认访问口令、WebSocket 交互与模型响应。
