# 数据结构智练：使用与部署说明

## 1. 本机启动与练习

双击项目根目录的 `启动应用.cmd`。浏览器访问 `http://127.0.0.1:8501`。若服务未运行，启动窗口需要保持打开；按 Ctrl+C 可停止。

首次打开时，若已配置云端模型则默认选择“云端 API”，否则使用“题库解析”。可在侧栏“辅导设置”切换。选择章节后直接作答；“筛选与跳题”可按难度、关键词筛选，并查看每题的作答状态。点击“给我一点提示”获取思考方向，选择选项并提交后显示判分和标准解析。

作答后选项会收起，点击“查看选项与我的作答”可重新展开。使用“下一题”顺序练习，或“下一道未练”跳过已练题目。答错自动进入“我的错题”，点击“开始连续复习”会建立本轮题目队列；重新答对后标记为已复习，使用“下一道待复习”继续巩固。“学习概览”统计真实提交次数、正确率和章节进度，可导出 JSON 记录。

同一道题、同一模型的提示和讲解会在当前会话中缓存，切换题目后返回仍可查看。重新练习、刷新浏览器或开启新复习轮次会重置当前辅导状态。云端与自训练模型支持作答后的连续追问，附带最近三轮的有限上下文；最新回答显示在前，近期历史可展开查看。学习助手的内容区可独立滚动，手机尺寸下会排列在题目下方。

正确率包含重复作答；练习进度按不同题目计数。推荐复习章节按待复习错题数量计算，不是模型推断的能力评分。空记录时不展示虚构数据。

本机模式所有浏览器窗口属于同一个个人学习空间，数据保存在 `runtime/study.db`，学习者标识保存在 `runtime/local_profile.json`。二者应一起备份。

## 2. 接入云端 API

将 `.env.example` 复制为 `.env`。若已经存在 `.env`，直接编辑，避免覆盖密钥。

```dotenv
LLM_BASE_URL=从服务商控制台复制的兼容接口基础地址
LLM_API_KEY=你自己的密钥
LLM_MODEL=qwen-plus
LLM_SEND_ENABLE_THINKING=true
```

BASE_URL 应以 `/v1` 结尾，不要重复写 `/chat/completions`。使用百炼时按账号所在地域和工作空间复制官方地址；示例里的 DashScope 地址只作为常见示例，以控制台当前地址为准。使用其他 OpenAI 兼容服务时，如果不接受 `enable_thinking` 参数，将 `LLM_SEND_ENABLE_THINKING=false`。

保存 `.env` 后展开侧栏“辅导设置”，点击“重新读取模型配置”，选择“云端 API”，点击一次提示按钮。也可以重启服务读取配置。成功后显示实际返回的模型名称和响应时间。设置齐全不等于已连通，以请求结果为准。HTTP 401 检查密钥；404 检查模型 ID 和地址；429 检查限流与余额；超时检查网络和模型服务。页面错误不会回显密钥或原始服务响应。

“重新读取模型配置”仅更新模型地址、密钥、名称及请求参数，不会修改访问口令或学习空间设置。此按钮适用于本机 `.env`；通过服务端环境变量部署时，应使用托管平台的配置管理功能。

请求仅在点击提示、讲解或追问按钮后发起；普通刷题不会调用模型。默认最多输出 700 Token，每个网页会话限制 80 次请求、至少间隔两秒。这是课堂演示的轻量保护，不代替服务商账户预算和正式平台级限流。

本机测试无需购买云 GPU。费用以服务商账单为准，本项目没有替用户开通、充值或创建付费资源。

## 3. 运行微调模型

先按《微调技术说明》完成云端训练。云端终端通过安全输入设置服务口令，至少 16 字符：

```bash
read -s -p "Model API key: " MODEL_API_KEY; echo
export MODEL_API_KEY
python training/serve.py --adapter outputs/lora
```

服务只监听 `127.0.0.1:8000`，不会自动公开到外网。另开本机终端，根据云平台实际 SSH 地址和端口转发：

```text
ssh -N -L 8000:127.0.0.1:8000 -p 实际SSH端口 实际用户名@实际主机
```

示例中的文字必须替换成平台提供的信息，不要原样执行。保持 SSH 窗口和云端服务都运行。然后在本机 `.env` 配置：

```dotenv
LOCAL_BASE_URL=http://127.0.0.1:8000/v1
LOCAL_API_KEY=与云端MODEL_API_KEY相同的口令
LOCAL_MODEL=ds-tutor-lora
```

点击“重新读取模型配置”，在侧栏选择“自训练模型”。服务同时提供 `ds-tutor-base`（禁用适配器）和 `ds-tutor-lora`（启用适配器），正式微调对比用评测脚本统一提示和生成参数。

该服务为课程演示用途：单模型串行推理、非流式响应、最多 4096 输入 Token、1024 输出 Token，采用确定性解码。为公平对比，收到 temperature 字段也不启用随机采样。正式生产环境还需要专用网关和更完善的配额、监控等能力。

## 4. 公网网页部署

2026-10-30 已部署至幕僚云：<http://140.210.92.250:17078>，公网 17078 映射到实例内 8890。网站需要访问口令；云端 API、答题复习、重启后记录恢复均已验收，用户确认手机流量能打开登录页。当前入口是 HTTP，尚未配置 HTTPS。实际服务器维护步骤见《幕僚云部署说明》，验证方法和限制见《幕僚云部署验收》。

最容易控制费用的路线是 Web 托管 + API 推理，Web 机器无需 GPU。部署入口为 `app.py`，依赖为 `requirements.txt`。Linux 常用启动命令：

```bash
python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

托管平台需要把公网 HTTPS 流量转发到此端口，并支持 WebSocket。将密钥作为服务端环境变量设置，不随源码上传。共享访问时设置：

```dotenv
APP_SHARED_MODE=true
APP_ACCESS_CODE=设置一个用于课堂演示的访问口令
APP_DB_PATH=/持久磁盘路径/study.db
```

共享模式每个新会话生成独立学习码，用户可以自行保存并恢复。学习码持有者可以查看对应记录，因此不要公开学习码。该功能不是正式账号体系。无持久磁盘的托管平台重启可能丢失 SQLite 数据，不应承诺长期保存。可先使用独立的演示数据空间，并提供记录导出。

AutoDL 的当前官方端口文档对开放端口有认证条件，个人用户可用 SSH 隧道访问自己的服务。不要默认把 GPU 实例的自定义服务地址当作供同学扫码的公开网站。公网部署需要按选定托管平台核实权限与可达性。

本次公网二维码为 `docs/screenshots/10-muliao-access-qr.png`。二维码只含网页地址，不含网站口令或 SSH 凭据。实例停止期间，二维码对应网页也会停止服务。

## 5. 提交与截图

`python scripts/package_project.py` 生成 `deliverables/数据结构智练_项目源码.zip`，不含 `.env`、虚拟环境或个人学习记录。云 GPU 上传此包即可获得训练脚本和数据。

真实训练产物需单独下载保存：`outputs/lora/`、`outputs/evaluation/`。把后者放回本机同路径后，模型实验室会读取实际比较结果。截图位于 `docs/screenshots/`：01～04 为题库流程，05～06 为本机真实 API 验收，07～09 为界面优化，10 为公网二维码，11 为云端登录页。它们不能作为微调成功的证据。
