# 界面与操作优化验收

日期：2026-10-29。应用：数据结构智练。本次迭代更新本机 Web 应用的界面与刷题流程。

## 1. 交互变化

- 工作台顶部展示真实的已练题目数、作答正确率、待复习题数，减少大幅横幅占用的空间。
- 章节选择保留在首屏，难度、关键词搜索与题目跳转收进“筛选与跳题”。题目列表显示未练、已答对或待复习状态。
- 选项整行可点击。提交后自动收起选项，优先展示判分、标准解析与易错点；可展开核对所有选项。
- 保留前后顺序切题，新增“下一道未练”，跳过已有作答记录的题目；找不到下一道时禁用按钮。
- 错题本支持建立连续复习队列。进入新一轮会重置队列题目的临时作答状态；答对后仍保留在本轮队列中，避免列表变化导致跳错题。可使用“下一道待复习”继续，也可主动结束。
- 学习助手的输出区可以独立滚动。提示与讲解按题目和模型配置隔离缓存，成功后禁用重复生成按钮；失败时保留重试入口。
- 模型追问携带最近三轮的有限上下文，最新回答显示在前，近期历史可展开查看。切换模型不会把旧模型的回答误标成新模型生成。
- 云端配置完整时，新会话默认使用云端模式。模型设置集中在侧栏“辅导设置”。

## 2. 验证方法与结果

运行 `python -m pytest -q`：**17 项测试通过**。包括题库判分与数据划分检查、持久化和幂等性、模型接口模拟、推理服务路由，以及以下界面流程：

1. 未选答案时阻止提交；答错进入错题本；重新答对后解除待复习状态；学习统计随真实记录变化。
2. 两道已答错题进入连续复习，均可重新作答，队列保持稳定，全部答对后显示完成提示。
3. “下一道未练”跳过已练题；空搜索结果能够一键恢复全部题目。
4. 提示按钮成功后禁用，普通重绘不重复请求；切换来源后缓存隔离，切回原来源可继续查看。
5. 连续追问包含上次讲解和追问内容，上下文长度受限制；提示任务不带入答后解析历史。

测试出现一条来自依赖的 AnyIO 别名弃用提示，不影响本次通过结果。所有新增 UI 自动化中的模型调用均使用本地模拟返回，未额外发起收费 API 请求；它们验证的是交互和请求上下文，不代表新的模型质量评测。

浏览器实测覆盖 1440 × 1000 桌面视口和 390 × 844 手机尺寸视口。检查了题目、选项卡片、答后解析、错题复习、进度统计、手机筛选浮层。手机尺寸下双栏改为上下排列，上一题/下一题按钮仍并排显示；这属于桌面浏览器的尺寸测试，未替代真实手机设备与公网访问验证。

功能操作使用独立 QA 服务（8502 端口）及 `runtime/ui-v2-qa.db`，不写入个人答题库。正式服务已在 8501 端口重新启动，保留原有 SQLite 学习记录，显示新版界面和已配置的模型名称。
