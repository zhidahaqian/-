## 3. 真实模型与答题流程

在服务器上以 `ds-tutor` 用户运行部署源码的 AppTest，使用与 Web 服务相同的环境文件，依次验证：

1. 未输入口令时学习空间不可见，错误口令被拒绝，正确口令可以进入。
2. 默认选择已配置的云端 API，对 DS001 的“给我一点提示”发起 **1 次真实请求**。
3. 接口返回模型名 `qwen3.8-max`，本次请求耗时 2.19 秒，接口报告输入 259 Token、输出 83 Token、合计 342 Token。模型名按接口返回记录，未独立验证服务商背后的权重身份。
4. 返回内容围绕连续存储、通过地址计算定位元素提供提示。这里是一条连通性样例，不是系统性的教学质量或性能评测。
5. 提示成功后按钮禁用，避免重复请求。
6. DS001 选择 B 提交，进入待复习；从错题本开始连续复习，选择 A 后答对。
7. 学习概览显示累计作答 2 次、练习题目 1 道、正确率 50%、待复习 0 道。

证据：`evidence/muliao-app-acceptance.json`，含真实模型返回文本、响应时间和 Token 用量，不含 API 密钥。

## 4. 重启与持久化

执行了一次 `systemctl restart ds-tutor`。服务恢复运行后，以新 AppTest 会话进入，确认新会话初始没有其他学习者的答题记录；再用验收学习码恢复，统计仍为 2、1、50%、0。

重启后 SQLite `quick_check` 返回 `ok`。数据库位于 `/data/ds-tutor/runtime/study.db`，验收记录属于单独的验收学习码。没有重启整个云实例；开机启动仅验证了 systemd 的启用配置。

证据：`evidence/muliao-restart-restore.json`、`evidence/muliao-service.json`。实际 Linux Python 依赖见 `evidence/muliao-linux-requirements.txt`。
