# 课堂展示与提交清单

## 建议展示顺序（约 4 分钟）

1. 说明定位：面向数据结构复习的轻量 Web 辅导应用。
2. 进入“栈与队列”，选择循环队列或出栈顺序题，请求提示。
3. 提交一个选项，显示判分、标准解析和实际模型讲解。
4. 打开错题本，重做一题，再展示统计变化。
5. 完成真实微调后，在模型实验室展示前后样例、训练损失与实际费用；若尚未训练，应明确说明当前演示的是云端 API 应用。

若尚未连接真实模型，明确说明当前是预设题库模式，不应将其作为大模型效果演示。最终课堂演示前必须完成真实模型接入。

## 报告结构建议

正文建议约 4000 字，不含参考文献。按照教师模板再确定封面、字号、行距、页码、目录与图表样式。

需求分析约 400 字；系统架构与功能约 700 字；模型选型与微调方法约 1000 字；实验评测约 800 字；部署与使用约 700 字；局限与总结约 400 字。

模板尚未提供，因此本目录中的工程说明不是已经按模板完成的正式作业报告。

## 展示前检查

- 真实模型能返回一条正常回答；启动脚本和 `.env` 配置就绪。
- 云端 GPU 仅在需要时开机；复核余额、SSH 通道和模型服务。
- 提前录制一次真实完整演示，以应对课堂网络故障。
- 备份源码、数据、适配器、训练日志、评测和截图。
- 不把包含密钥的配置窗口、学习码或云平台登录凭据拍入截图。
